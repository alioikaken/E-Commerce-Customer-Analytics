# Аналитика покупателей в E-Commerce

Структура реляционной базы данных, тестовые данные и аналитические SQL-запросы для анализа поведения и продаж в интернет-магазине (PostgreSQL).

## Состав проекта

- `schema.sql` — SQL-скрипт создания 15 таблиц с первичными и внешними ключами.
- `seed.sql` — тестовые данные по покупателям, товарам, заказам, оплатам, отзывам, возвратам и активности пользователей.
- `queries.sql` — аналитические запросы по каналам привлечения, сегментам, выручке, товарам, оплатам, отзывам и возвратам.

## Таблицы базы данных (15 таблиц)

1. `registration_sources` — источники регистрации покупателей
2. `customer_segments` — сегменты покупателей
3. `customers` — данные покупателей
4. `customer_addresses` — адреса доставки
5. `categories` — категории товаров
6. `products` — каталог товаров и цены
7. `coupons` — промокоды
8. `discounts` — скидки на товары по периодам
9. `orders` — заказы и их статусы
10. `order_items` — позиции внутри каждого заказа
11. `payments` — оплаты и способы оплаты
12. `reviews` — оценки и отзывы покупателей
13. `returns` — возвраты заказов
14. `return_items` — возвращённые позиции товаров
15. `customer_activity` — история действий пользователей

## Как запустить

1. Выполнить `schema.sql` для создания таблиц.
2. Выполнить `seed.sql` для заполнения тестовыми данными.
3. Запустить запросы из `queries.sql` для получения аналитики.
